# Project: Random Quiz Application

## Objective

Build a Quiz Application using HTML, CSS, and JavaScript.

The application should contain a collection of **100 General Knowledge questions** stored in a JavaScript array. Every time the page loads (or when the user starts a new quiz), the application should randomly select **10 unique questions** without repeating any question.

Each question should display four options, and the user should be able to select only one option for each question using radio buttons.

After clicking the **Submit** button, the application should:

* Check all selected answers.
* Calculate the total score out of 10.
* Display the final score to the user.

The application should also provide a **Reset** or **Submit** button that clears the current quiz and Submit & generates a new set of 10 random questions.

## Requirements

* Store all questions in a JavaScript array of objects.
* Each object must contain:

  * Question
  * Four options
  * Correct answer
* Display only **10 random questions** from the 100 available.
* No question should appear more than once in the same quiz.
* Use radio buttons for answer selection.
* Prevent page refresh when submitting the form.
* Display the final score after submission.
* Allow the user to reset the quiz and generate a new random set of questions.
